# Gateway Haunts & Holly

Holiday blog covering Halloween and Christmas, which also includes a dedicated section on holiday events in the St. Louis area. Built with Next.js 15 (App Router), TypeScript, and CSS Modules.

This is an in-progress personal project. Hoping to launch the site by August 2026. The repo is public so others can view the code and design approach, but the work is not open source. All code, designs, and content are © Raeann Hoelker and may not be copied, republished, redistributed, or claimed as your own. If you'd like to discuss the project, please reach out.

## Running Locally

**Requirements:** Node.js 18.17 or later, npm

Clone the repo and install dependencies:

\`\`\`bash
git clone https://github.com/RaeannW/gatewayHauntsAndHolly.git
cd gateway-haunts-and-holly
npm install
\`\`\`

Create a `.env.local` file in the project root:

\`\`\`
NEXT_PUBLIC_SITE_URL=http://localhost:3000
\`\`\`

Run the dev server:

\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) in your browser.
